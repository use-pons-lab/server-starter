# 安全性と脆弱性報告

対象: ServerStarter 0.4.0 Beta 7

ServerStarterはMinecraft Java Editionのサーバーを利用者のPC上で起動し、利用者が許可した場合だけ必要な通信設定を行います。

## 安全のための制限

- Windows Firewall全体を無効化しません。
- Minecraftサーバーに必要なTCPポートとJava実行ファイルだけを許可します。
- 管理者権限が必要なFirewall操作はWindowsの確認画面を表示します。
- DMZ設定を推奨・自動設定しません。
- ルーターの管理者パスワードを取得、保存、自動入力しません。
- 配布ワールドのZIP展開では、保存先外への展開、シンボリックリンク、異常に大きな内容を拒否します。
- アプリが管理していない場所はワールド削除対象にしません。

## 利用者が知っておくこと

友達をインターネットから参加させる間は、選択したMinecraft用ポートを外部へ公開します。参加者制限（Whitelist）を設定し、遊び終わったらアプリからサーバーを停止してください。自動設定したポート開放は停止時に解除を試みますが、PCやルーターの突然の電源断後は次回起動時に回収を試みます。

本ベータ版は未署名です。Windows SmartScreenに発行元不明の警告が表示される可能性があります。入手元が案内するSHA-256とファイルのSHA-256が一致することを確認してください。警告を無条件に無視したり、セキュリティ機能を無効化したりしないでください。

## 報告

脆弱性や不審な挙動を見つけた場合は、公開・サポート連絡先へ、アプリのバージョン、再現手順、個人情報を伏せたログを送ってください。アカウント情報、ルーターのパスワード、ワールド全体は送らないでください。
